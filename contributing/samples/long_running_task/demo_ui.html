    1️⃣
    Task Runs
    Long-running analysis processes data in chunks
    2️⃣
    Checkpoint Created
    Every 10s, state is serialized and compressed
    3️⃣
    Two-Phase Commit
    Blob → GCS, then metadata → BigQuery
    4️⃣
    Recovery Ready
    If crash occurs, resume from last checkpoint
