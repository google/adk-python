# Sample JSON Data

Use this nested JSON as input for the transform script:

```json
{
  "user": {
    "name": "Alice",
    "age": 30,
    "address": {
      "city": "Seattle",
      "state": "WA",
      "zip": "98101"
    }
  },
  "orders": [
    {"id": 1, "total": 42.50},
    {"id": 2, "total": 18.75}
  ]
}
```
